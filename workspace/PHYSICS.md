# 原生數值與接觸合約（P1）

核心使用 Q32.32 int64；乘除採 signed 128-bit 中間值並向零截斷。
設定由 Python Fraction 精確轉換（最近值，半取偶數）。平方根整數向下取整。
沒有平台浮點三角函式；擊球方向使用固定 31 次 CORDIC 與版控常數，0° 為精確軸向。

每 tick 重力或滾動摩擦僅施加一次；之後按接觸時間切段。
`advance` 只回傳下一個場地接觸，外層可先插入更早的球棒／手套接觸。
`trace` 是可獨立測試的場地接觸協調器，不含比賽判決。
單 tick 上限 32 個接觸；超限明確拋出 `physics_contact_limit`。

掃掠時間為 [0, 2^32] 整數分數；最終事件寫入器須將 2^32 正規化為下一 tick 的 0。
AABB、接球圓柱與觸壘區含邊界。直線進入時間向下量化至 Q0.32，精確可表示切線保留原值。
圓弧出界時間採首次離開的整數時間（向上量化），避免反覆穿牆；反彈位置向場內解離 1 個 Q32.32 單位。
圓柱切線以 256-bit 無號乘積比較，保留 Q32.32 座標，不先降精度。
移動手套以球與球員相對掃掠判定；球員高度使用固定參數。

球員採每 tick 速度變化限制與速度上限。到目標觸碰區直接將速度歸零；非目標壘正常通過。
此層只回傳幾何候選，不判誰安全、封殺、得分或換局。
同時接球候選按 `(sub_tick_q, player_id)` 排序。其他規則同時事件由後續 Python 規則層處理。

本期獨立驗收無 Bot、無模型、無 Electron。Windows + Zig 0.13.0 已測試；尚不宣稱跨平台 D3。
