# 版本與首版範圍

首版專案版本為 0.1.0，規格基準為 baseball-bot-spec/1.0.0；階段版本識別保留在記錄中，避免升版後改變舊回放。

| 對戰版本 | 球物理 | 地圖 | 判定差異 |
| --- | --- | --- | --- |
| 1.0.0-dev.P4 | P4 | P4 | 首個外部 Bot 完整封存版本，保留原揮空與移動解讀 |
| 1.0.0-dev.P5 | P4 | P4 | 已啟動但窗口已結束的揮棒仍記揮空好球；JSON 邊界拒絕非法 Unicode；拒絕的小數只作稽核 |
| 1.0.0-dev.P7（預設） | P4 | P7 | 普通守備移動有煞停距離；公平區外野牆與矩形邊界限制移動目標及位置 |

P7 的跑者目標壘仍使用進入觸碰區立即停止的例外；普通守備移動不得套用該例外。邊界碰撞會停止速度，並回傳子 tick 停止時間。初始公平區站位不得位於牆外。舊 P4 地圖仍走原函式，不能用新移動近似重播。

相容性按 schema/rules/physics/map 版本與明確建置指紋比對。已支援的 P4、P5 舊建置識別列在 replay.py，相容路徑經完整舊記錄測試；未知識別直接 unsupported_version。P0–P3 的開發記錄使用對應 Git tag 執行。

權威核心不使用亂數判接球或打擊。RNG 為 xoshiro256**／SplitMix64；固定小數是 Q32.32，序列化 bb-canon-v1。Windows x64 + Zig 0.13.0 已跑 golden vectors；其他平台尚未宣告 D3。

省略規則依計畫書：換人、指定打擊、盜壘／牽制、暴投／捕逸進壘、不死三振、觸擊、投手犯規、妨礙、內野高飛必死、再見結束、跨打席申訴、傷勢與體力。沒有真人操作、網路多人、訓練平台或 Blender 美術製作。

目前使用幾何球員與視覺 profile，GLB/glTF 匯入及骨架動畫只預留資產規約。模型偏移、原點修正、比例及錨點只影響顯示，不參與判定。

Job Object 的 256 MiB 是可信任 worker 與 Bot 的合計 committed-memory 上限；加上程序數限制、2 秒 watchdog、64 KiB stdout 行與 1 MiB stderr 上限。這是程序／資源隔離，並非 OS 安全沙箱。主機故障只會 aborted，不會包裝成正式勝負。

FPS 與 seek 數據為參考機測量；背景離屏 1080p 驗收不等於所有硬體、前景視窗或未來美術資產的效能保證。影格 cache 可重建，不是唯一權威來源。記錄雜湊提供完整性與一致性，不是簽章或反作弊認證。
