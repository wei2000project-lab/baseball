# 對戰啟動器

以後只要雙擊 **啟動遊戲.bat**。

1. 選擇「客隊 Bot」與「主隊 Bot」，可用「交換主客隊」對調。清單自動掃描 bots 內的資料夾，也能按「選檔案」選 .cpp／.py／.exe，或按「資料夾」選整個 Bot。
2. 選輸出根目錄；場次名稱留空就自動命名，每場建立自己的資料夾，不覆寫舊記錄。
3. 按「開始對戰」。視窗顯示進度、比分及訊息；完成後可按「觀看本場回放」。預設勾選「完成後自動開啟回放」，可自行取消。

`GPT_tactical_cpp` 等新增到 bots 的資料夾會出現在清單，可按「重新掃描 Bot」更新。選到 .cpp 時由既有主機自動編譯，不需要先手動打包。上一回選擇會保留。

- 「短場」在 10 個模擬秒到時後完成該局上下半局；不是 10 秒牆鐘內一定結束。
- 可選完整 15 模擬分鐘或自訂 1–3599 模擬秒。Seed 預設 42，可自行修改。
- 每場記錄仍是輸出資料夾中的 match.txt；「開啟既有回放」可選先前的比賽資料夾。
- 「停止對戰」只停止此啟動器建立的這場程序樹；尚未封存的記錄不算完整賽。關閉正在對戰的啟動器會先詢問。
- 錯誤會顯示在下方，完整訊息保存在 launcher/build/logs；C++ 編譯錯誤也會顯示。

原生 Windows GUI 執行檔已編譯在 launcher/build。批次入口會直接使用快取，需要時自動重新編譯啟動器，無須自行輸入命令。若搬動整個專案，仍可從同一批次入口啟動。它沿用本專案既有的 Python、Zig、Electron 環境，不是另外一套安裝版；請保留整個專案。

設定、編譯產物及日誌均在忽略的 launcher/build，遊戲規則與 Bot 策略沒有改動。自行修改啟動器原始碼後，批次入口也會選用新的建置，不覆寫已在使用的舊執行檔。

維護者背景驗收：`python launcher/verify_launcher.py`。只建立自己的不可見視窗，包含成功、取消與失敗案例，不操作桌面、不開檔案對話框、不啟動回放。
